# Mean-Unemployment-rate-from-2008-Q1-Q4-to-2018-Q1-Q4-

In this project, I analyzed **unemployment rates** across South African provinces between **2008 and 2018**. I used `Python`, `Pandas`, `Statistics`, and `Matplotlib` to load the CSV dataset, group records by province, calculate the **mean unemployment rate** for each province, and present the findings in a horizontal bar chart. This project helped me practice working with `CSV` files, grouping data, calculating averages, and creating data visualizations.
